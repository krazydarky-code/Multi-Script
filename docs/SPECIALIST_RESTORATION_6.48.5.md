# Reviewed specialist restoration

The user-supplied v24 release removed 663 skills and 39 Blender virtual workflows. The retained 241 skill definitions are preserved byte-semantically. This update adds eight reviewed topics under their prior stable IDs, with new domain-specific steps and inspect/execute/verify contracts. It does not reimport the old bulk catalog.

| Restored skill | Reason and verification contract |
| --- | --- |
| blender-texture-baking | Explicit receiving images, projection/cage diagnostics, color-space/channel choices and actual destination-material inspection. |
| blender-shape-keys | Vertex correspondence, meaningful expression ranges, combined rig poses and export/deformation checks; replaces the former generic texture-map advice. |
| blender-geometry-nodes | Editable sockets, field/instance behavior, controlled realization, measured evaluation cost and tested export. |
| blender-sculpt-retopology | Preserved sculpt, deformation-aware loops, projection checks, diagnostic bakes and tested bends. |
| blender-gltf-export | Complete dependency package, installed-version clip handling, validation and destination reimport. |
| figma-prototyping | Real state transitions and prototype playback when advertised; annotated states when the connected tool cannot author links. |
| figma-developer-handoff | Real component/token mapping, asset package, behavior contracts and measured implementation comparison. |
| canvas-svg-ui | Editable SVG structure, portable resources, rendered/imported evidence and explicit separation from application behavior. |

Two removed Blender workflows return as guidance: asset-delivery and profiler-evidence. Their methods require actual native export/import or measurements before completion claims. Blender gameplay networking, economy, combat and duplicate UI workflows remain removed because they add irrelevant engine claims. Other generic name-substitution skills stay removed.

Primary reference entry points are stored with each skill. Relevant source observations include Blender's instance/realization memory behavior and version-sensitive glTF action organization, and Figma's typed prototype variables and source-of-truth component handoff. Consult the installed tool/version before using changing APIs. Reference data does not grant new capabilities, change permissions or prove execution.
