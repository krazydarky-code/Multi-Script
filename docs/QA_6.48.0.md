The release gate validates versions, source syntax, catalogs, all content-script chains and packaging exclusions. CI runs 58 targeted suites and rejects environment skips. The published verification receipt identifies the exact tested main commit and workflow run.

The theme matrix checks independent menu/chatbar palettes, composer portals, narrow layouts, actual painted contrast and motion preferences. It also checks the immediate light-to-dark control text change, covering the low-contrast transition found and corrected during this release's local sweep.

New updater checks use a real trusted local HTTPS server for download progress, truncated responses, bounded transient retries and redirect restrictions. Signed temporary installations exercise cross-process locking, readable progress while busy, insufficient disk space before writes, corrupted-backup recovery without partial restoration, post-commit receipt recovery and private-file retention. Browser-worker tests cover concurrent checks, bridge preference restoration, worker restart, wrong-folder setup and browser-managed pending updates. Headless Chromium checks the shipped Updates panel at 390px and 1280px, including actual progress, disabled mutation buttons, setup mismatch and reload readiness.

The Roblox production checks compare canonical method data with the generated browser library, load actual scoped skill references through MCPManager and verify the three supplied-reference provenance hashes. All 904 skill IDs remain available. Tests check engine selection, section filtering, full GUI/animation methods, actual trusted prompt delivery with the enhancer off and companion-write research/evidence guards.

Existing coverage includes 16 provider browser/transport fixtures, Notion/Vani runtime round trips, Venice Agentic/Classic, private ClickUp, Figma contracts, six effort levels, engine isolation, tool schemas, bounded repeated reads/failures, task/phone progress, HTTP pairing/control, native-plugin source staging and rollback. Roblox plugin behavior executes in a Lua VM with Roblox API fixtures; native editor rendering and scheduling are not emulated.

Publication verification downloads the real HTTPS feed and release archives, validates signatures, size and hashes, then upgrades a checksum-pinned 6.47.0 installation in a temporary folder using its actual updater client. It compares every managed installed file and retains private configuration, custom skills and engine preferences. Frozen Public 6.42.0 remains byte-for-byte unchanged. New backend recovery behavior is tested separately using the shipped 6.48 implementation.

Live editor/gameplay, every provider account/model, asset permissions, a physical phone and local firewall behavior remain outside these fixture checks. Runtime methods guide models in context; they cannot guarantee model compliance or provide missing tools.
