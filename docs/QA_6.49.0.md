# Multi-Script 6.49.0 verification

Blender Workspace uses real background Blender with a locally bundled Three.js/lil-gui UI. Real Windows x64 tests run Blender 4.5.15 LTS from the portable archive whose size and SHA-256 match the official Blender checksum listing.

Native integration coverage includes existing typed Blender tools and validated schemas, headless Python edits, mesh modifiers, keyframes and animated GLB, parented world-coordinate conversion, failed-edit rollback, saved .blend reopening, real Cycles CPU PNG, GLB/FBX/Blend export, target separation, stale-project rejection, disabled-engine enforcement and authenticated HTTP origin/Host/path boundaries. The browser test uses the actual local service, actual Blender and the shipped bundle; it creates a real primitive, edits it through lil-gui into bpy, plays real exported animation, scrubs the native frame, displays a genuine render, downloads GLB, reloads with its cookie and checks desktop/phone layout.

Provider regression tests use deterministic provider DOM/model responses and real local tools where stated. Ultra retains its 249 skills, twelve manuals and compact on-demand methods. Chat Studio does not gain engine execution. Update tests cover signed local replacement, protected project data and setup behavior. The portable runtime cache is outside releases and is not overwritten by an extension update.

Coverage does not certify all Blender versions/OSes, every Blender feature in glTF, all target-engine importers or authenticated AI providers. Public GitHub publishing remains blocked by the suspended publisher account; a signed local update candidate is not a public feed publication.
