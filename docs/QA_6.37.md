# Multi-Script 6.37.1 verification

Both deliverable packages contain the revised extension and local bridge. Ultra is the last stop on the actual reasoning slider, and nine live scenes mount on the independently themed chatbar.

6.37.1 replaces four tiny controls with one labeled Studio button and a contextual menu containing large labeled actions and execution mode. Additional visual checks passed in dark and light mode at 1280 px and dark mode at 480 px. The menu stayed inside the viewport and above the input, and closed after focus changes and resizing. The Studio visibility setting was exercised through its actual label control. Light-mode icons and the selected execution mode have explicit contrasting colors.

The final executed verification set passed **31/31 test scripts**: 16 JavaScript/browser suites and 15 Python suites. The release gate separately checks JavaScript/Python syntax, manifest references, version agreement, catalogue integrity and required files. The builder checks archive CRCs, edition agreement and exclusion of private runtime data.

Browser coverage includes Ultra persistence and delivery of changed settings on the next turn, all nine live chatbar scenes, viewport-position preservation, a non-blank pixel screenshot check, reduced motion, the compact Studio menu, keyboard navigation and contextual dismissal, minigame input, the new settings tabs, Discord/donation changes and the existing 23-check chatbar docking suite. Four new-provider fixtures exercise real DOM input/send/role-reading paths and reject ClickUp human-channel composers.

Runtime coverage includes workshop ownership, unique ratings/stars, explicit installation, payload/rate limits, an actual HTTP community service with authentication and a remote client, atomic competing co-work claims, lease expiry, real AVI generation with image frames, public/dev policy checks and an actual workspace file/edit/build/test workflow. The exhaustive skill/tool audit retrieved, queried and recommended all 904 skill entries. Existing creative-asset tests generated SVG icon packs, sprite/contact sheets and styled UI source files.

These results establish the local code paths tested. They do not establish perfect output quality, permanent model training, universal provider compatibility, or real engine playtests on every user's machine. The engine-tool tests use fixtures/mocks or local project files where native editors are not available. The recorder was tested with deterministic captured frames; OS desktop-capture permission was not exercised against your real desktop.

Live provider research: Venice Classic returned the exact guest-model compatibility response and its actual composer/message selectors were inspected. Vani Chat redirected to marketing in both HTTP and browser checks. Authenticated Vani and ClickUp Brain remain unverified. Crax was corrected to crax.gpt.lol; direct browser navigation still failed DNS here, leaving live DOM verification pending. Community workshop source is included and locally HTTP-tested; no public server was deployed.

Dev edition has no added product caps. Public edition has a 256 KiB edit/write payload cap, 60-second command cap and disables the background-command option. Both keep existing workspace/Run commands permissions and provider account limits.
