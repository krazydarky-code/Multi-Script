# Multi-Script 6.39.0 — Ultra integration

- Adapted upstream GPL source 1.24.19's bounded task-routing algorithm and efficient execution policy into Multi-Script's Ultra prompt path. Eight task-specific methods cover interfaces, code, diagnosis, performance, data, worlds, assets and motion, with engine-aware guidance and the existing tool/skill catalogue.
- Ultra now has a selected-only violet/cyan identity, colored native slider/endpoint, an inline workflow summary and a compact brand label in the chatbar. Existing themes and live scenes remain in place. Dark/light, reduced-motion, forced-color and narrow-view layouts are supported.
- Centralized effort presentation across saved-setting hydration, keyboard/pointer input, menu rebuilding, import and reset. Lower effort explicitly supersedes prior Ultra policies and removes Ultra task methods from future prompts.
- Kept Critic as a separate Agent prompt add-on and preserved shared acknowledged-send, pacing, provider and local-tool transport behavior.
- Included source attribution and the GPL license for the adapted code; excluded separately licensed bundled assets, alternative runtimes and foreign protocol assumptions.

See `docs/SOURCE_METHODS.md` for the exact selection and integration boundaries. These workflows guide the current provider model and use actual available tools; they do not unlock a model, service or entitlement.
