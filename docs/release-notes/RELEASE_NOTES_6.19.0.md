# Multi-Script 6.19.0 — Universal

## Prompt enhancer that actually follows its settings

- The enhancer remains provider-neutral and now adds task-shaped execution guidance for code, UI, data, media, scenes, networking, and research.
- **Review before sending** now opens a real editable review dialog with Add brief, Use original, and Cancel actions. Previously the saved preview switch was descriptive but the kickoff path sent automatically.
- Connected-engine facts, live-tool facts, execution approach, and original-first ordering are independently functional and persisted.
- Enhancer and effort settings now round-trip in portable settings backups and appear in privacy-safe diagnostics.

## Universal execution-effort harness

A new Adaptive / Quick / Standard / Deep / Maximum control works on every supported AI site. It changes requested implementation depth without claiming to change a provider's hidden reasoning controls. In Notion AI it is carried inside Multi-Script's prompt-only startup harness and remains separate from the preferred-model request.

## MCP catalog integrity

The direct-tool catalog remains at 230 tools. Generic MCP discovery continues through the existing live engine catalog, server routing, schemas, and resource transport. Multi-Script does not add duplicate wrappers for capabilities already advertised by a connected MCP server.

## UX and reliability

- Added an accessible, keyboard-friendly enhanced-prompt editor (`Esc` cancels, `Ctrl/Cmd+Enter` continues).
- Preserved provider boundaries: no model-picker automation, plan bypass, or provider-specific enhancer dependency.
- Expanded deterministic tests for cross-provider availability, prompt settings, settings backup, and content-script load safety.
