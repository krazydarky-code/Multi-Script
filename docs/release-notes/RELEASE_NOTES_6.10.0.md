# Multi-Script 6.10.0 — Keyless Local Audio

- Added free offline procedural WAV generation requiring no account, network request, quota, or API key.
- Local generation is now the safe default for UI sounds, impacts, explosions, lasers, whooshes, footsteps, rewards, alarms, rain, wind, engine hum, and generic stylized effects.
- Added deterministic seeds, loop seam crossfading, normalization, metadata, checksums, and native-engine handoff instructions.
- ElevenLabs remains an optional explicit cloud provider for complex natural material; existing private key handling remains intact.
- Skills and tools still improve the active provider model; generated audio is a real artifact and must be imported and tested through live engine MCP tools.
