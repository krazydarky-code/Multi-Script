# Multi-Script 5.1.0 — Roblox Studio Companion

This release adds an optional Roblox Studio plugin, a loopback-only readiness endpoint, and a direct capability audit for the exact native Studio MCP catalogue. It also fixes stale tool schemas surviving MCP process restarts.

The plugin is intentionally complementary: Roblox Studio remains the source of the native 60+ MCP tools. Multi-Script improves visibility, readiness, safe project scaffolding, and diagnostics without claiming undocumented capabilities.

It also updates the Notion AI adapter for the current “Do anything with AI…” composer, including placeholder overlays and unlabeled send controls.
