# Multi-Script 4.2.1 — Task-First Quality Boost

Specialized skills and tools directly improve the game-development aspects they own. A request is executed normally and directly; relevant skill knowledge silently improves design, implementation, polish, accessibility, performance, and verification. Simple prompts receive conservative professional defaults. Detailed prompts retain all explicit constraints. Skill orchestration remains optional for genuinely complex work and is never a substitute for the requested deliverable.

The release includes a regression for “make me a good UI for this Roblox game, classic”: it produces a Roblox-inspired classic visual direction, responsive input states, and an immediate implementation directive without exposing an internal rewritten brief.
