# Multi-Script 6.50.0 Dev

Preserves and extends all 249 skills, existing styles, twelve Ultra manuals and useful prior tools. This release combines the supplied production additions with provider, performance and signed-delivery fixes.

- Provider transport: retains the ChatGPT native-editor transaction fixes, ClickUp editor boundaries, reference/draft preservation and confirmed-send protection. Automatic continuation remains bounded and waits for live generation. Polite/add/fix/recreate requests now receive one scoped execution reminder when the AI only pastes code; the original task is retained and raw example code is never auto-executed.
- Effort and layout: preserves the shared Auto/Floating layout, density/effort controls, donation button and Ultra appearance options. Repeated progress/output setup is not mandatory. Relevant methods are deduplicated; expanded full manuals are retrieved on demand.
- Forge/OMNI: lazy Canvas drawing, complete selected packs, preserved prior generations, optional demos, offline Roblox documentation and a compact 522-entry reference catalogue. Six reviewed native Luau modules complement existing GUI/VFX/animation workflows. References and pseudocode are not reported as live implementation.
- Headless Blockbench: explicit pinned preparation, 21 native file-based tools, textures/UVs/meshes/animation/validation/export and an optional frozen GPU renderer. Existing editors and projects remain intact. See [Blockbench setup](../BLOCKBENCH.md).
- Root Obsidian vault: Setup creates and connects `Multi-Script Memory` beside `extension` and `runtime` on each PC. It holds the full skills/tool/manual seed and imported original archives/media, with bounded bridge recall/read/remember. Large private data never enters release archives; updates preserve the vault. No cloud subscription or third-party memory service is required. See [vault setup](../OBSIDIAN.md).
- Updates: green download badge and accessible Update/Later overlay, retained signing key, public new-account feed, serial publishing, host-directed cooldowns and CI-gated immutable publication. Existing idle/draft/session/recovery protections remain.

The frozen 6.42.0 Public companion is unchanged. Run Setup from the complete permanent folder you actually load in the browser; stop active sessions before applying, reload the extension and refresh provider tabs. See [verification](../QA_6.50.0.md) for executed checks and coverage boundaries. Fixture passes do not promise zero defects or certify every signed-in provider account/device.
