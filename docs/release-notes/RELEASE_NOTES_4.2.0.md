# Multi-Script 4.2.0 — Automatic Capability Stacks

Every skill now participates in a capability graph and has at least four complementary related skills. Meaningful requests automatically select a 3–8 skill stack spanning design, implementation, polish, optimization, and validation. Activation returns an execution contract that requires real MCP project changes and verification; it cannot be treated as a plan-only completion.

New dedicated production tools cover professional animation, textures/materials, art direction, UI/UX, VFX, and audio. The bridge now exposes 40 tested virtual tools while retaining exactly 500 validated skills.
