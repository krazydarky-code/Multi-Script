# Multi-Script 6.14.0 — Optional Arena Routing

- Added **Off — Normal Arena** beside the Arena Direct Max profiles.
- Off mode sends no Direct Max starter profile and no per-turn model-routing envelope.
- Normal engine-connected startup still loads the engine studio capabilities.
- Engine-free Chat Studio still loads its usual skills and starter behavior.
- Selected model-targeted profiles and optional untargeted Direct Max remain available when deliberately enabled.
