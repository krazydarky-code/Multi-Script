# Multi-Script 6.42.0

Co-work now combines editable, ordered correction/goal queues with a project-filtered task board, acceptance checks, evidence and blockers. The bridge enforces completion requirements and preserves existing tasks through migration.

Provider sessions discovers supported tabs, reads bounded local briefs and starts/assigns tasks explicitly through each tab's own provider transport. Drafts, stale contexts and duplicate/uncertain dispatch are protected. Background execution is an explicit option. Task counts and acceptance progress reflect the shared board. The dashboard supports phone-sized layouts; remote phone pairing is not included.

Vani now recognizes “Stop it”, waits for native thinking/generation to finish and applies a 2.5-second quiet interval before feedback. Complete-looking frozen JSON cannot trigger early execution. Reused-node readiness, startup phase reporting, startup cancellation and a final generation check before Send address the reported stuck-starting and interrupted-response cases.

Skills gain project/engine activation, enable/disable controls, candidate/user-verified states, Markdown imports and library methods kept for a project. Active methods reach every prompt with the enhancer and Critic disabled. Ultra retains the final slider stop and adds a task-specific delivery contract.

Code Flight is fully rebuilt in its own Workspace tab with the actual Multi-Script icon, layered Terminal/Orbit/Dawn worlds, Arcade/Practice modes, precision scoring and keyboard/touch controls. Leaving the page pauses it. New idea is a smaller icon. Six additional themes include three live scenes shared by the menu and chatbar.

PlazCode patterns were adapted to Multi-Script's runtime and transport; GPL attribution is retained. See [the workflow guide](../WORKSPACE_REVAMP_6.42.md) and [verification report](../QA_6.42.md). Provider authentication, account/model access and native editor coverage retain the previously documented limits.

Extract one complete edition, rerun Setup from its permanent folder, reload the extension/provider tabs and restart the bridge. Use a matching 6.42.0 extension/runtime pair.
