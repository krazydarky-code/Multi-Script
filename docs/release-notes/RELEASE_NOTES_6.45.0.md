# Multi-Script 6.45.0 Dev

Ultra's twelve specialist manuals now include authored craft methods, research
and critique procedures, five style directions and Roblox Studio, Godot, Unity,
Blender and desktop Software Builder/Code playbooks. Full methods are retrieved
through the local manual tool with engine context, while task prompts remain
bounded and relevant. Lower effort immediately disables Ultra's policy. All 904
built-in skill contracts now include domain-specific craft guidance, also returned
by the Studio Director. Existing scope, custom-skill enablement, tool schemas and
provider pacing remain authoritative.

Settings → Help → Updates adds daily signed-release checks/downloads and explicit
idle Apply & reload for registered unpacked Dev installs. The native host checks
signatures, archive hashes, version, identity, permissions and managed paths.
Private data/settings are preserved; modified source is protected and interrupted
applies have journaled recovery. Store installations use their browser update
service. No remote JavaScript is injected.

**Publishing is not configured yet:** a real GitHub repository and private
publisher signing key must be set up before online updates can reach users.
[The update guide](../UPDATES.md) explains the one-time setup and each release.
Older versions need the first configured build manually once. New permissions,
external editor plugins and runtime dependencies still need manual setup.

Dev is the current build. Public 6.42.0 remains byte-for-byte unchanged in the
combined bundle. See [executed QA and coverage boundaries](../QA_6.45.0.md).
