# Multi-Script 4.0.0

First release-ready Multi-Script package.

Highlights:
- Multi-provider control center with per-provider skills, speed/quality loops, creative routing, and usage controls
- Roblox, Unity, Godot, Blender, Figma, Canvas/SVG, and arbitrary stdio MCP workflows
- 306 reusable skills
- 17+ bridge-native planning, verification, handoff, and asset tools
- Notion Auto preferred-model requests sent once per new chat
- Provider benchmark dashboard
- Organized runtime/extension/tests/docs structure
- Release verifier, privacy/security documentation, store assets, and reproducible packaging

Read `docs/INSTALL.md` before installation and `docs/PRIVACY.md` before publishing.
