# Multi-Script 6.37.0

Ultra is the last stop of the real reasoning/effort slider in Agent settings. The bar's effort icon opens it directly. The saved choice is delivered in provider startup instructions and changed settings are sent with the next user turn or tool result. Ultra calls for primary-reference/style research, real artifact integration, tests and bounded critic passes. It does not modify provider account limits or secretly change their own reasoning controls.

All nine live scenes now mount independently on the chatbar, including composer portals: Aurora, Lava, Nebula, Matrix, Fazbear's, Scream, Myers, Slender and Jason. The bar can inherit the menu or select its own theme. Motion preferences stop ambient animations. Compact action icons preserve the existing docking and appearance.

The shared prompt now contains concrete UI/UX/GUI, building, modeling, animation, VFX and engineering workflows, plus ten style profiles. All 897 existing skill IDs received practical instructions; seven focused packs bring the catalogue to 904. Retrieval returns concise instructions instead of repeating the compatibility metadata wall. Checklist-only specialist wrappers are retired from the default tool catalogue but remain callable for old chats.

New Idea reads the current conversation and local memory on click and requests three actual project-specific directions. It waits for a choice before editing. Critic runs up to three review/fix passes through the existing tool loop; Stop cancels it and an explicit environment blocker stops further passes. Ultra can arm these passes for implementation requests. Both use the active provider model and do not pretend to create independent model instances.

Sandbox/Ask is available from a chatbar picker. Code mode and Software Builder have their own Code & Build tab. The development build has no added product caps. The public build limits edit/write payloads to 256 KiB, commands to 60 seconds and disables background processes; these limits are enforced in the Python workspace layer.

Co-work is a persistent task board shared across provider tabs through the same local bridge. Claims are atomic with renewable 30-minute leases, owner checks, progress notes, completion and release. Concurrent workers should own disjoint files/assets.

The skill workshop supports JSON authoring, explicit installation, publishing, search/pagination, stars, ratings and feedback. It works locally and includes a separate authenticated community server and bridge client. Community hosting is supplied as deployable source, not an already-hosted global service. See WORKSHOP.md for setup and abuse limits.

Screen recording saves a real MJPEG AVI of at most five seconds and returns a timestamped contact sheet for vision-capable providers. Setup includes Pillow. OS screen-capture permission is still required where applicable. A recording is evidence, not a replacement for running a playtest.

Vani, Crax, Venice and ClickUp adapters and provider listings are included. Venice Classic composer/message structure and an actual guest-model response were checked live. Vani's chat redirected to its marketing page here, Crax's supplied hostname did not resolve, and authenticated ClickUp Brain was unavailable. Those adapters are not labelled verified. See PROVIDER_QA_6.37.md.

Donation and ad-support controls were removed. The Discord icon now opens https://discord.gg/5Q6vvNcpM6.
