# Multi-Script 4.3.0 — Engine Virtual Tools

This release adds 200 real virtual tool profiles rather than only adding skills: 50 each for Roblox Studio, Unity, Godot, and Blender. They improve UI, animations, graphics, shaders, VFX, models, textures, art, audio, gameplay, systems, optimization, tests, and production. Four compact MCP gateways list, match, inspect, and run them without dumping 200 schemas into every model context.

Automatic Prompt Skills silently match the exact request, run only the strongest profiles, preserve every explicit requirement, and then proceed directly to actual engine work.
