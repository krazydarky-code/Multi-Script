# Support

Join the [Multi-Script Discord](https://discord.gg/5Q6vvNcpM6) for help, or report a reproducible issue in the project's issue tracker. Include the version, provider, bridge status and steps to reproduce. Remove private prompts, credentials and personal files from diagnostics before sharing them.

Optional development support is available through [Ko-fi](https://ko-fi.com/multixscript), the GitHub Sponsor button and the chatbar heart. Donations do not unlock provider subscriptions or bypass quotas.
