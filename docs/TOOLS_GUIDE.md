# Multi-Script tools guide

_Generated by `tools/gen_tools_guide.py` from the live registries - do not edit by hand._

## How the tools work

1. You chat with an AI site (Notion AI, ChatGPT, Claude, Gemini, DeepSeek, Kimi, GLM, Qwen, Arena, Meta). The Multi-Script bar adds the tool list to the conversation.
2. The model answers with a tool call. The extension parses it and sends it to the **local bridge** (a Python process on your computer).
3. The bridge runs the tool: **native tools** (`ms_<engine>_*`) generate and run real engine code (Luau in Studio, C# in Unity, GDScript in Godot, Python in Blender) or write project files; **built-in tools** (`ms_*`) plan, audit, remember, read the screen or manage a workspace; the **Roblox companion** (`msrb_*`) edits the open place through a Studio plugin.
4. The result (clipped or paginated according to Settings > Limits) goes back into the chat so the model can read, verify and continue.

Tools marked **writes** change your project. Everything else only reads or plans. Native generators never bundle audio/art assets: you pass the asset ids or paths, and missing ones are reported as warnings.
