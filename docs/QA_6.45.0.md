## Updater

Real RSA-3072/SHA-256 signed metadata and the actual publisher signing CLI are
tested against temporary Dev archives. Runtime signature verification has no new
dependency; the publisher/test tool uses cryptography. Checks cover wrong keys or
signatures, channels, unsafe/insecure URLs, versions, identity, new permissions,
archive content hashes, managed paths, local source edits and obsolete-file removal.
Corrupt cached ZIPs or partial staging metadata are detected and can be downloaded
again without manually deleting update state.

An actual temporary installation is staged without changing installed code, then
upgraded. Private config, studio-data, native launcher, logs and unrelated user
files survive. Simulated disk failure rolls back; a simulated killed process leaves
a journal that recovers after restart, including an interrupted atomic-write file.
Native apply refuses an active bridge. Filesystem updates remain outside the model
tool catalog and require the native host.

The real downloader uses a local HTTPS server with a temporary trusted test CA.
TLS verification stays enabled. Tests reject oversized advertised/no-length
bodies, HTTPS-to-HTTP redirects and credential-bearing/file URLs.

Worker tests cover install-type detection, active/generating/starting chats,
drafts, queued prompts, unconfirmed sends and enhancement activity, explicit idle
apply/reload, saved preferences, automatic-check opt-out and managed-store updates.
Real content-script Help/Updates UI tests cover staged/unconfigured states and
390px light/dark layouts. [Dark UI](verification-6.45.0/Updates-dark.png),
[light UI](verification-6.45.0/Updates-light.png).

**Live boundary:** the public repository, feed and release key are not configured.
No public download/update, store submission or installed browser/native-host upgrade
is claimed. Follow [GitHub setup and publishing](UPDATES.md), configure before the
first published build and manually install that build once. New permissions and
external editor plugins/dependencies still require manual updates.
