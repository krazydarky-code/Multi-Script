The release gate checks matching versions, packaged source, manifests and syntax.
GitHub CI runs 41 targeted suites and rejects environment skips. The exact main
commit, workflow URL and results are attached as CI-verification-results.json.
Only successful CI on the current main commit can publish its signed Dev feed.

levels twice through trusted user sends, with enhancement/Critic off, immediate
Ultra demotion and stable transmitted task IDs. Actual agent-loop fixtures verify
two unchanged native reads followed by bounded pause, research/full-method gating,
a single build and one motion-evidence reminder. Chat studio tests remove globally
connected Godot from instructions/catalog/dispatch. Arena tests hold feedback while
both candidates generate, wait for selection and never replay uncertain clicks.

All 904 skills are retrieved and validated, all 278 built-in tool schemas checked,
and full text/image resource delivery, traversal boundaries, licenses and scoped
style rules tested. The actual world_stats Lua body runs in Lupa against denied
Lighting.Technology and normal mocks, retaining place counts in both. Schema tests
cover declared target_file repair without inventing a missing path or Studio ID.

The actual HTTP phone frontend runs in headless Chromium with the real remote
broker, worker and content-script queue: pairing, live plan/stage/estimate,
follow-ups, queue pause/resume, Stop receipts, revocation and disabling. Progress
tests check evidence-required steps, initial URL transitions, stale IDs, restoration,
automatic response stages, both chatbar icons, focus and clock-only DOM updates.

The broader local theme matrix and full settings sweep are also executed.

Existing coverage includes all 16 provider DOM/transport fixtures, real Python
skill/SVG round trips in Venice Agentic/Classic, Vani and private ClickUp fixtures,
provider error streaming, Figma contracts, recording AVI/contact-sheet generation
with fixture frames, signature/TLS/update limits and temporary-install rollback.

upgrading a checksum-pinned public 6.45.1 temporary install while retaining private
configuration, custom skills and engine preferences.

These are observed fixture/runtime tests, not certification of every live provider
account/model, a physical phone, native Studio/Blender/gameplay or every firewall.
No Blender binary was available to render/export the supplied creature recipes;
their Python syntax, resource access and handoff were checked. Estimates are rough
step-based ranges, not hidden model thinking or guaranteed completion times.
