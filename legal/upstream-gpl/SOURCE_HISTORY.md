## Adapted implementation

PlazCode's `core/ultracode.js` has a bounded task router: match the actual request, deduplicate methods and add only relevant content. Multi-Script adapts this algorithm into `ULTRA_METHODS` and `ultraMethodsPrompt` in `extension/core/studio-workflows.js`. The methods cover interfaces, engineering, diagnosis, performance, authoritative data, world layout, assets and motion. Their instructions were rewritten for Multi-Script's actual multi-engine architecture, existing skill catalogue and ordinary-JSON command transport. No foreign skill IDs, tool server or secondary startup protocol is introduced.

The efficient execution policy preserves working systems and current architecture, reuses valid evidence and avoids repeating passing checks without cause. Uncertain API calls require real documentation; claims about speed, screenshots, imports and playtests need actual results. Roblox guidance applies to an explicit Roblox task or a sole Roblox connection, with explicit other-platform requests taking priority. It does not redirect a React website into a connected Studio. Relevant methods travel with the task once. Selecting Ultra during an active task also supplies its methods through the existing acknowledged settings update, alongside the next tool result.

PlazCode's violet/cyan selected-effort text treatment was adapted in `extension/overlay.css`. Multi-Script keeps its native six-position slider: Ultra remains position 5 after Maximum. Selecting it reveals an inline Inspect & research / Build & integrate / Verify & refine summary, colors the slider and selected stop, accents the chatbar border, and adds a small noninteractive Ultra label beside the existing brand. It introduces no chatbar button or Studio popover. Existing theme surfaces, live scenes, density and visibility preferences continue to apply. The state follows hydration, slider input, menu rebuilding, settings import and Agent reset, including bars portaled into a provider composer.

Lowering effort immediately clears the selected-only treatment and supplies an explicit replacement effort instruction. This cannot erase text already in a model's context, but it tells the active model to stop applying prior Ultra methods/research requirements. Critic remains a separate persistent setting; its extra review instructions are absent when disabled. Ultra still requires meaningful verification of its own work.

## Deliberate integration boundaries

The full 61 KB Ultra source module is not pasted into prompts. Multi-Script sends its bounded relevant methods, then uses its existing skill and tool discovery for detailed workflows. The native slider keeps keyboard Home/End and arrow behavior rather than being replaced with PlazCode's custom dropdown.

No upstream IDE, AgentScript workspace runtime, bundled binary, DeepSeek-specific language/approval policy, SyphoDev skill bundle, Check-UI module, font, art collection, model credential or machine configuration was imported. Those bundles have separate licenses and tool/style assumptions. Their presence in the ZIP does not grant tools or asset rights. Multi-Script retains its permissions and acknowledged-send/pacing pipeline from 6.38.0.

The source archive SHA-256, modified source paths and preserved GPL license are in `vendor/plazcode/NOTICE.md` and `vendor/plazcode/LICENSE`; see also `THIRD_PARTY_NOTICES.md`. Runtime symbols and product UI use Multi-Script names, with provenance retained in source comments and notices.
